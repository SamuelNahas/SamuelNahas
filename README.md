## 🚀 Featured Projects

### 📊 [SH Meta Games](https://github.com/SamuelNahas/Limitless-stats)

Competitive **Pokémon TCG metagame analytics platform** built from public tournament data.

- Collects and processes tournament results from Limitless TCG
- Deck popularity, performance and matchup analysis
- BO1 and BO3 statistics
- Representative decklists and tournament history
- Personal Battle Journal with optional cloud synchronization
- Automated data collection and deployment

**Stack:** `Next.js` · `React` · `TypeScript` · `Python` · `Supabase` · `GitHub Actions`

🌐 [Live application](https://samuelnahas.github.io/Limitless-stats/)

---

### 🏆 TCG Tournament Check

Tournament operations platform designed to assist **Pokémon TCG judges and tournament organizers**.

- Tournament and player management
- Digital decklist submissions
- Automatic 60-card deck validation
- Physical deck-check workflow
- Judge accounts and occurrence tracking
- Penalty and deck-check PDF reports
- Responsive interface for desktop, mobile and iPad
- Docker deployment with automatic CI/CD
- Self-hosted GitHub Actions runner
- Persistent SQLite storage and public HTTPS access

**Stack:** `TypeScript` · `Node.js` · `SQLite` · `Docker` · `GitHub Actions` · `Nginx`

> Private repository — developed for real tournament operations.

The platform provides an interactive environment for learning fundamental computer architecture concepts through a simplified machine language and computer simulator.

Work around the project includes:

- academic research
